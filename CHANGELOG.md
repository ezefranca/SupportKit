# Changelog

All notable changes to SupportKit are documented here. The project follows Semantic Versioning.

## Unreleased

## 1.0.0 - 2026-09-03

- Initial Swift 6.2 core and SwiftUI packages.
- Configurable form fields, localized copy surface, and visual theme.
- Opt-in diagnostic preview, bounded breadcrumbs, and deterministic redaction.
- Atomic offline queue, recent-content suppression, retry backoff, and delivery events.
- HTTPS receiver transport with raw-payload idempotency digest.
- Vendor-neutral server ports and orchestration, plus optional Cloudflare hosting and a GitHub App destination adapter
  with immutable, exact private-or-public repository visibility policy.
- Privacy manifest, DocC entry points, security documentation, tests, and CI.
