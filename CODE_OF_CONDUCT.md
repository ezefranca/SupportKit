# Code of conduct

SupportKit is committed to a welcoming, harassment-free community. Be respectful, assume good intent while addressing
impact, give actionable technical feedback, and protect private or security-sensitive information.

Unacceptable behavior includes harassment, discrimination, threats, sustained disruption, publishing another person's
private information, or using support data outside its intended purpose. Maintainers may edit, remove, reject, or ban
participation that violates these expectations.

Report conduct concerns privately to the project owner through the contact options on
[Ezequiel's GitHub profile](https://github.com/ezefranca). Reports will be reviewed as confidentially and promptly as
practical. Good-faith reporters will not face retaliation.

This policy applies in project spaces and when someone is publicly representing the project.
